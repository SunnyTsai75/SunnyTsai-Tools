📊 如何知道有多少人玩過？

如果您未來想要知道點擊人數或玩家數量，可以考慮以下幾種簡單的做法：

  • 做法 A：在 GitHub 網站上查看流量（最推薦、最簡單）
    如果您將這個連結放在您的 GitHub 網站（本頁面）上，只要玩家是透過您的 GitHub 網站點擊進去的，您就可以直接在該 GitHub 專案的 「Insights」 -> 「Traffic」 面板中，看見每天有多少人造訪了您的網站、點擊了哪些連結。
